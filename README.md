# Шесть кранов — демо-сайт бара

Одностраничный сайт небольшого пивного бара с меню из шести сортов, афишей музыкальных выступлений, мобильным редактором контента и формой бронирования.

**Демо:** https://vash-site-demo.github.io/bar-shest-kranov/

## Что реализовано

- адаптивный первый экран, меню, афиша и блок бронирования;
- редактирование всех сортов, цен и событий через удобную форму;
- сохранение демонстрационных изменений в `localStorage` текущего браузера;
- восстановление исходных демонстрационных данных;
- валидация заявки и подготовка текста бронирования без имитации отправки на сервер;
- доступные модальные окна, мобильное меню и поддержка `prefers-reduced-motion`.

Все названия, цены и события демонстрационные. Для публикации настоящего сайта бара потребуется подключить CMS: локальное хранилище не синхронизирует изменения между устройствами.

## Стек

HTML, CSS, JavaScript, Vite. Изображения и шрифты хранятся локально. Источники указаны в `CREDITS.md`.

## Запуск

```bash
npm install
npm run dev
```

## Проверка

```bash
npm run build
npm run test:browser
```

Браузерный тест проверяет меню, афишу, форму, редактор, сохранение данных, модальные окна и адаптивность на ширинах 375, 768, 1024 и 1440 пикселей.
